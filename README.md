# Shared Cart & Group Ordering for Zomato

A product teardown and design case study exploring how Zomato could evolve group ordering from a basic shared cart into a real-time, coordination-first experience.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm run start
```

## Included PRD

The updated 24-page Product Requirements Document is included in `public/` in both PDF and DOCX formats. The website's hero and footer buttons open the PDF:

`/Shared_Cart_Group_Ordering_PRD_BhanuPrakash.pdf`

## Notes

- Next.js 15.5.29 is pinned in `package.json`.
- `.next/`, `node_modules/`, and environment files are excluded by `.gitignore`.
- The financial model is illustrative and uses the assumptions displayed on the page; it is not Zomato guidance.
- This is an independent portfolio case study and is not affiliated with Zomato.
